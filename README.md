# PaperLink Reader

영어 원문과 한국어 번역 PDF를 나란히 읽고, 문장과 단어를 확인하는 **Windows 로컬 브라우저 리더**입니다.

> **처음 사용할 때: PDF2zh 계열 프로그램으로 한국어 번역 PDF를 먼저 만들어야 합니다.**
> 이 README는 **PDFMathTranslate-next(PDF2zh-next)로 번역 → PaperLink에서 비교하며 읽기** 순서를 안내합니다. PDF2zh는 별도로 설치하며 PaperLink에 포함되어 있지 않습니다. 이미 준비된 번역 PDF가 있다면 번역 단계는 생략할 수 있습니다.

[실행 ZIP 다운로드](https://github.com/Cortinuum/PaperLink-Reader/releases/latest) · [PDF2zh-next 공식 저장소](https://github.com/PDFMathTranslate-next/PDFMathTranslate-next) · [PDF2zh-next 공식 사용 문서](https://pdf2zh-next.com/)

## 만든 목적

논문을 번역해서 읽더라도 작은 표현 차이가 조건, 가능성, 주장 강도와 전문 용어의 의미를 바꿀 수 있습니다. 번역문만으로 판단하기 어려운 문장에서 원문으로 돌아가고, 두 PDF에서 같은 위치를 찾는 반복을 줄이기 위해 만들었습니다.

요약 대신 **논문 전문을 원문과 함께 읽는 것**이 목적입니다. 문장을 선택해 원문·번역문을 옆 패널에서 비교하고, 필요한 질문만 GPT에 보내며, 모르는 단어와 직접 확인한 뜻을 단어장에 모읍니다. 특정 학문 분야를 전제로 하지 않습니다.

## 주요 기능

| 기능 | 할 수 있는 일 |
| --- | --- |
| PDF 비교 읽기 | 영어 원문·한국어 번역문 나란히 표시, 기본 75% 배율, 확대·축소와 페이지 이동 |
| 문장 연결 | PDF에서 문장을 선택해 대응 문장 후보 확인, 연결 직접 수정·자동 연결 복원, 문장 영역 테두리 켜기·끄기 |
| GPT 비교 패널 | 원문·번역문을 보며 질문, 모델·추론 수준 선택, Markdown 답변 표시 |
| 선택형 검토 | 원문 근거, 번역 정확성, 대안 번역, 용어·약어, 문장 구조, 뉘앙스·주장 강도, 불확실성 |
| 오프라인 영한사전 | 단어 더블클릭으로 뜻 조회, 대표 사전 결과와 접을 수 있는 추가 결과, 용례 검색 |
| 개인 단어장 | 뜻·설명을 직접 추가하고 저장 |
| 논문 보관함 | PDF 쌍 추가, PDF 변경, 제거와 휴지통 복원 |
| 읽기 환경 | 다크 모드, 접히는 보관함, 크기 조절 가능한 GPT 패널, 기록 내보내기 |

## 사용 순서

### 1. PDF2zh-next 설치·실행

Windows에서는 공식 문서가 안내하는 실행 ZIP 방식을 권장합니다. PaperLink와 **서로 다른 폴더**에 설치하세요.

1. [공식 Windows 설치 안내](https://pdf2zh-next.com/getting-started/INSTALLATION_winexe.html)에서 연결한 [PDF2zh-next Releases](https://github.com/PDFMathTranslate-next/PDFMathTranslate-next/releases)를 엽니다.
2. 처음 설치한다면 `pdf2zh-<version>-with-assets-win64.zip`을 받습니다. 글꼴과 모델 등 리소스를 포함하는 파일입니다.
3. ZIP 전체를 압축 해제하고 `pdf2zh` 폴더의 `pdf2zh.exe`를 실행합니다.
4. 준비가 끝나면 번역 화면이 기본 브라우저에서 열립니다. 자동으로 열리지 않으면 터미널에 표시된 주소를 확인하세요. 공식 기본 주소는 `http://localhost:7860/`입니다.

실행 파일이 시작되지 않으면 공식 설치 안내에 있는 Microsoft Visual C++ x64 재배포 패키지 안내를 확인하세요. 파일명과 화면은 버전에 따라 달라질 수 있습니다.

### 2. 영어 → 한국어 번역 설정

PDF2zh-next의 번역 화면에서 다음 항목을 설정합니다.

| 항목 | 설정 |
| --- | --- |
| 입력 PDF | 영어 논문 원본 |
| 원문 언어 | English / `en` |
| 번역 언어 | Korean / `ko` |
| 번역 서비스·모델 | 설치한 버전에서 지원하고, 본인이 사용할 권한이 있는 엔진 |
| 출력 폴더 | 원본과 구분되는 별도 폴더 |
| 출력 종류 | **번역문 전용 `mono` PDF 생성 유지** |

번역 엔진은 별도로 선택·설정해야 합니다. PDF2zh가 무료 공개 프로그램이어도 외부 번역 서비스까지 무료라는 의미는 아닙니다. 지원 엔진과 설정은 [공식 번역 서비스 안내](https://pdf2zh-next.com/advanced/Documentation-of-Translation-Services.html)를 확인하세요. Google·Bing의 예전 무료 연동은 현재 공식 문서에서 지원 중단으로 표시하므로 기본 사용법으로 권장하지 않습니다.

API 키가 필요한 엔진은 **자신의 PC에 열린 PDF2zh 설정 화면에서 직접 입력**하세요. 키를 GitHub, README, 스크린샷이나 채팅에 올리지 마세요. 유료 API라면 실행 전에 해당 제공자의 요금·잔액·사용 한도를 확인하세요. 채팅 서비스 구독이 별도 API 사용료까지 포함한다고 가정하면 안 됩니다.

외부 엔진을 선택하면 번역할 논문의 추출 텍스트와 번역에 필요한 문맥 등이 해당 제공자로 전송됩니다. 선택한 엔진·설정에 따라 범위와 보관 정책이 달라지며, PaperLink의 로컬 PDF 보기와는 별개입니다.

### 3. 첫 2쪽 시험 후 전문 번역

1. PDF2zh에서 페이지 범위를 **`1-2`**로 지정해 시험 번역합니다.
2. 결과 PDF를 열어 한국어 글꼴, 두 단 본문 순서, 수식·기호·단위, 그림·표·인용 번호와 겹침·잘림·누락을 확인합니다.
3. 문제가 있으면 번역·레이아웃 설정을 조정한 뒤 같은 범위를 다시 확인합니다.
4. 결과가 괜찮으면 페이지 범위 제한을 해제하거나 전체 페이지를 지정해 전문을 번역합니다.

시험본을 PaperLink에 넣을 때도 원문과 번역문의 **페이지 수·페이지 크기·대응 순서가 맞아야 합니다**. 번역한 쪽만 출력하는 옵션을 사용했다면 같은 범위의 원문 사본을 준비하세요. 원본은 보존하세요.

PDF2zh-next 출력은 보통 다음처럼 구분됩니다. 실제 파일명은 버전과 출력 설정에 따라 달라질 수 있습니다. [공식 출력·페이지 옵션 안내](https://pdf2zh-next.com/advanced/advanced.html)

| 파일 | 용도 |
| --- | --- |
| `paper.pdf` | 영어 원문. PaperLink의 **영어 원문 PDF** 칸에 선택 |
| `paper-mono.pdf` 등 `mono` 결과 | 한국어 번역문만 있는 PDF. **한국어 번역 PDF** 칸에 선택 |
| `paper-dual.pdf` 등 `dual` 결과 | 원문과 번역문을 합친 대역 PDF. 별도 열람용이며 PaperLink의 번역 PDF 칸에는 넣지 않음 |

**PaperLink에서는 원문 + `mono` 두 파일을 나란히 표시하므로, `dual` 파일이 없어도 대역으로 읽을 수 있습니다.**

### 4. PaperLink 실행·PDF 불러오기

1. [최신 PaperLink 실행 ZIP](https://github.com/Cortinuum/PaperLink-Reader/releases/latest)을 Windows 10/11 x64 PC에 내려받아 전체 압축을 해제합니다.
2. `Start_PaperLink.cmd`를 실행하면 기본 브라우저에서 리더가 열립니다.
3. 왼쪽 **내 논문** 영역을 열고 **PDF 불러오기**를 선택합니다. 처음 실행한 빈 보관함에서도 PDF를 추가할 수 있습니다.
4. 영어 원문 PDF와 한국어 `mono` PDF를 각각 선택하고 **보관함에 추가**를 누릅니다. 제목은 선택 사항입니다.
5. 왼쪽 영어 원문과 오른쪽 한국어 번역문을 함께 읽습니다. 종료할 때는 `Stop_PaperLink.cmd`를 실행합니다.

두 PDF는 페이지 수와 페이지 크기가 같아야 하며 **두 파일 합계 최대 100MB**입니다. 선택한 PDF는 로컬 보관함에 복사하고 원본을 수정하지 않습니다.

실행 ZIP에는 PaperLink용 Python과 패키지가 포함되어 있습니다. 시스템 Python이나 PATH를 바꾸지 않으며, 리더를 위한 별도 Python 설치는 필요하지 않습니다. **PDF2zh 번역기 설치와 번역 서비스 설정은 별도**입니다.

### 5. 문장 비교·단어 찾기

- 기본은 **PDF 보기**입니다. 필요할 때 문장 보기로 전환하거나 **문장 영역 보기**를 켜 문장 선택 범위를 확인하세요.
- 문장을 선택하면 대응 원문·번역문을 **GPT 비교** 패널에서 확인할 수 있습니다. 자동 연결이 잘못되었으면 상단의 **연결 수정**으로 직접 고칠 수 있습니다. 아래 순서를 참고하세요.
- 질문을 입력하고 필요한 **추가 검토** 항목을 선택합니다. 여러 항목을 함께 선택할 수 있으며 해당 요청이 질문 칸에 표시됩니다. 체크를 해제하면 자동 추가한 요청도 사라집니다.
- GPT 기능은 별도의 ChatGPT 로그인과 전송 동의가 필요합니다. **모델·추론 수준**은 도구·모델에서 고르며, 기본값은 Luna와 가장 낮은 추론 수준입니다. 이용 가능한 모델과 한도는 계정에 따라 달라집니다.
- PDF 단어를 더블클릭하면 로컬 사전의 뜻을 조회합니다. **단어 선택** 모드도 사용할 수 있습니다. 다른 사전 결과는 펼쳐 볼 수 있고, 직접 확인한 뜻과 설명을 저장할 수 있습니다.
- **용례 검색**은 외부 검색을 엽니다. 단어 뜻 창은 PDF 표시 영역 클릭, 닫기 버튼 또는 Esc로 닫습니다.

| 단축키 | 동작 |
| --- | --- |
| `←` / `Page Up` | 이전 페이지 |
| `→` / `Page Down` | 다음 페이지 |
| `Home` / `End` | 첫 / 마지막 페이지 |
| `Ctrl + I` | GPT 비교 패널 열기·닫기 |
| `?` | 단축키 도움말 |

질문·메모·페이지 번호 등 입력 칸에서 글을 쓰는 동안에는 페이지 이동 단축키가 작동하지 않습니다.

### 6. 문장 연결 직접 수정

1. 수정할 페이지를 열고 **문장 보기 / PDF 보기 왼쪽의 연결 수정**을 누릅니다. 미리 원문을 선택했다면 그 문장부터 열립니다.
2. 왼쪽에서 **영어 원문 한 문장**을 선택합니다. 선택한 원문은 파란색으로 표시됩니다.
3. 오른쪽에서 대응하는 **한국어 문장을 체크**합니다. 여러 문장을 연결할 수 있으며 초록색으로 표시됩니다. 체크를 해제하면 연결에서 제외됩니다.
4. 위쪽 **원문 ↔ 번역문 미리보기**로 선택을 확인합니다. 다른 원문으로 이동해도 저장 전 변경은 창 안에 유지됩니다.
5. **연결 저장**을 누르면 이 페이지에서 바꾼 연결을 함께 저장하고 PDF 강조 표시와 GPT 비교에 반영합니다. 취소·닫기는 저장 전 변경을 버립니다.

**선택 문장 자동 연결로**는 해당 원문의 수동 지정을 해제하는 변경을 준비합니다. 미리보기를 확인하고 연결 저장을 눌러 적용하세요. 번역문을 하나도 선택하지 않고 저장하면 잘못된 연결을 끊을 수 있습니다. 수동 지정은 다시 열어도 유지되며 자동 계산보다 우선합니다. 현재는 같은 페이지 안의 연결만 수정합니다.

자동 연결은 아래 규칙으로 로컬에서 계산하며 API를 사용하지 않습니다.

- **영역 분리:** 가로 전체를 쓰는 설명문·제목을 경계로 두 단 읽기 순서를 정리합니다. 위치·글자 크기·설명문 표기를 이용해 본문, 그림·표 설명, 제목, 각주, 머리말·꼬리말·여백 정보를 나눕니다. 서로 다른 영역과 다른 그림·표 번호를 자동으로 섞지 않습니다. 이 영역 분류 자체도 휴리스틱이며 틀릴 수 있습니다.
- **기준점과 구간:** 영역 안에서 양쪽에 한 번씩 나타나는 그림·표·수식 번호, 수치·단위 등을 기준점 후보로 사용합니다. 순서가 맞는 기준점 사이에서 길이·숫자·위치를 비교해 일대일·분할·병합 후보를 계산합니다.
- **애매하면 보류:** 다른 후보와 규칙 점수가 거의 같거나 번호·동일 단위의 수치가 충돌하고 길이 차이가 지나치면 연결을 비워 둡니다. 일부 의심 연결은 연결을 유지하면서 확인 대상으로 표시합니다. 점수는 의미 정확도의 확률이 아닙니다.
- **확인 필요:** 상단 **⚠ 확인 N**을 누르면 해당 문장들을 모아 볼 수 있습니다. 연결 수정 창에서 이유와 후보를 확인하고, 후보 버튼으로 선택한 뒤 미리보기를 검토해 저장하세요. PDF의 문장 영역 표시와 문장 보기에도 의심 연결을 표시합니다. 미연결 문장은 대응 번역문을 지정하기 전 GPT 비교 질문을 보낼 수 없습니다.
- **수동 연결 고정:** 저장한 연결은 우선 적용하고 주변의 자동 연결을 다시 계산합니다. 수동 연결이 교차하거나 범위가 겹치면 그 안의 나머지 문장을 억지로 추정하지 않습니다. 자동 연결로 되돌리면 해당 고정점을 해제하고 재계산합니다. 여러 페이지에 규칙을 학습시키거나 사용자 수정으로 번역 모델을 훈련하는 기능은 아닙니다.

의미 일치를 보장하는 기능은 아니므로 중요한 문장은 원문을 직접 확인하세요.

### 7. PDF 변경·제거·업데이트

내 논문 목록에서 **PDF 변경**으로 원문 또는 번역 PDF를 교체하거나 **제거**할 수 있습니다. 제거한 논문쌍은 휴지통에서 복원할 수 있습니다. PDF 내용이 바뀌면 이전 논문쌍과 읽기 기록은 휴지통에 보관합니다.

개인 논문·기록·단어장은 앱 폴더의 `data/`에 저장됩니다. 업데이트 전 앱을 종료하고 기존 `data/`를 백업하세요. 새 버전에서도 이 폴더를 보존해야 기록이 유지됩니다. ChatGPT 연결 정보는 해당 Windows 사용자 계정에 별도로 보호해 저장하므로 다른 PC에서는 다시 로그인해야 할 수 있습니다.

## 사전 자료와 적중률

대표 사전은 커뮤니티 보충입니다. 테스트 논문 11쪽 전체에서 출현 횟수 기준 적중률은 커뮤니티 보충 **87.13%**, 공개 사전 **75.61%**였습니다. 비교 방법은 [dictionary/comparison.json](dictionary/comparison.json)에 있습니다. 단어 조회율이며 문맥상 뜻의 정확도가 아닙니다. Quick 사전은 제외했습니다.

## 개인정보·GPT 연결

PDF 보기·사전 조회는 로컬 처리합니다. 원본 PDF를 수정하지 않습니다. 용례 검색을 누르면 표제어를 외부 검색 서비스로 보냅니다.

GPT 질문은 사용자가 로그인과 전송 동의를 한 경우 선택 문장·대응 번역·문맥과 최근 대화를 첨부합니다. ChatGPT 연결의 실제 이용 가능 여부와 한도는 계정·공식 서비스 정책에 따릅니다. 유료 API 키로 자동 전환하지 않습니다. 로그인 연결 정보는 해당 Windows 사용자 보호 기능으로 저장하며 저장소·ZIP에는 포함하지 않습니다. 보관한 대화가 ChatGPT 웹 목록에 동기화되지는 않습니다.

PDF2zh에서 사용하는 번역 엔진 설정과 PaperLink의 GPT 비교 로그인은 **별개의 연결**입니다. 한쪽을 설정했다고 다른 쪽까지 연결되지는 않습니다.

## 한계·문제 해결

| 상황 | 확인할 점 |
| --- | --- |
| 번역 PDF가 등록되지 않음 | `dual` 대신 `mono`를 선택했는지, 페이지 수·크기와 100MB 제한 확인 |
| 일부 페이지만 번역되어 원문과 맞지 않음 | 같은 페이지 구성으로 다시 출력하거나 해당 범위의 원문 사본 준비 |
| 단어·문장이 선택되지 않음 | 스캔 PDF는 OCR로 텍스트층을 준비해야 할 수 있음 |
| 원문과 번역문 연결이 어색함 | 자동 연결은 후보이며 의미 검증이 아님. PDF에서 직접 비교 |
| 번역 글자가 깨지거나 본문이 겹침 | PDF2zh 결과를 먼저 확인하고 번역·글꼴·레이아웃 설정 조정 |
| GPT 질문이 되지 않음 | ChatGPT 로그인 상태, 전송 동의, 계정에서 지원하는 모델과 이용 한도 확인 |

복잡한 단·수식·약어·그림 안의 문장은 잘못 추출될 수 있습니다. PDF2zh도 수식·그림·배치 보존이나 번역 정확성을 완전히 보장하지 않으므로 중요한 내용은 원문으로 검토하세요. 사전에도 오역·누락이 남을 수 있습니다.

## 개발 환경

GitHub의 소스 ZIP은 실행환경이 포함된 **릴리스 실행 ZIP과 다릅니다**. 소스에서 시작하려면 `Setup_PaperLink.cmd`로 앱 폴더 안에 전용 Python 환경을 구성한 뒤 `Start_PaperLink.cmd`를 실행합니다. 이 초기 설정에는 인터넷이 필요합니다. 의존성은 `requirements.txt`에 고정했습니다.

```powershell
.\.venv\Scripts\python.exe -m unittest test_review_options test_chatgpt_account test_pdf_import test_library_management test_local_dictionary test_sentence_links test_alignment_rules
node --test test_markdown.cjs test_question_prompt.cjs
```

실행 ZIP은 `build_release.py`로 생성합니다. 사전 재구축은 `build_dictionary.py`를 사용합니다. 사전 원자료와 출처 고지는 `dictionary/sources/`에 있습니다.
