ChatGPT로 로그인

기존 ChatGPT 계정으로 로그인하고, 허용된 구독 한도로 리더 안에서 대화합니다. 별도 유료 API 키는 사용하지 않습니다.

로그인은 OpenAI 공식 페이지에서 진행합니다. PaperLink에 비밀번호를 입력하지 마세요. 연결 정보는 Windows 계정 보호 기능으로 암호화해 이 PC에 저장합니다.

Plus 등 계정의 공유 사용 한도가 적용됩니다. 한도 도달 시 유료 API로 자동 전환하지 않습니다. 이 대화는 리더에 저장되며 ChatGPT 웹 대화 목록과 동기화되지 않습니다.

PDF 불러오기

변경할 PDF만 선택하세요. 선택하지 않은 파일은 유지합니다. PDF 내용이 바뀌면 이전 논문쌍과 읽기 기록은 휴지통에 보관합니다.

번역문만 들어 있는 PDF를 선택하세요. 원문과 페이지 수·페이지 크기가 같아야 합니다. 두 파일 합계 최대 100MB.

선택한 PDF는 이 PC의 보관함에 복사합니다. 원본을 수정하지 않으며 이 과정에서 외부로 전송하지 않습니다.
